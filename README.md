# ⛵ Tanwi's Interactive Story Portfolio

An interactive, story-driven portfolio website featuring a 3D ship sailing through the chapters of my journey — from college to Red Hat, AI, DevConf, and beyond.

## ✨ Features

- **3D Landing Page** — Animated ocean with a ship and character using Three.js
- **Era-Based Navigation** — 9 unique "eras" of my journey, each with distinct visual themes
- **Game-Style + Hybrid Nav** — Scroll through the story or click the side navbar to jump
- **Responsive Design** — Beautiful 2D animated fallback on mobile devices
- **Interactive Particles** — Mouse-reactive particle field background
- **Tilt Cards** — 3D tilt effect on achievement cards

## 🛠️ Tech Stack

- React + TypeScript + Vite
- React Three Fiber + Drei (Three.js)
- Framer Motion
- Tailwind CSS
- GitHub Pages

## 🚀 Quick Start

```bash
npm install
npm run dev
```
